# Code of Conduct

## Our Pledge

We pledge to make participation in our project and community a harassment-free experience for everyone.

## Standards

Be respectful, inclusive, and collaborative. No harassment, trolling, or discrimination of any kind.

## Enforcement

Project maintainers may take action to remove or reject contributions that violate this code of conduct.

## Attribution

This Code of Conduct is adapted from the Contributor Covenant (v2.1).
