# Contributing to SnapSBOM

We love your input! We want to make contributing to SnapSBOM as easy and transparent as possible.

## Development Process

We use GitHub to host code, track issues and feature requests, and accept pull requests.

## Pull Requests

1. Fork the repo and create your branch from `main`
2. Make your changes
3. Add tests if applicable
4. Ensure the code compiles and tests pass
5. Issue a pull request with a clear description

## Code Style

- Rust: Follow `rustfmt` conventions
- TypeScript: Follow standard conventions
- Keep changes focused and minimal
